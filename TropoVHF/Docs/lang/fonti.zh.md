## 1. 提交人的住所

IC8TEM 观测可以对工作进行框架化,在来源中可以找到反馈.

- 意大利地理学要求疏通. 与多尔萨尔站,Promontory站和离站后数十公里的岛屿相接相接,分流贡献由主边缘的弗雷斯内尔参数来计算出,而不只是平滑地. 会议:比较563 MHz的不规则地形(里约热内卢,27个点在5至30公里之间),最好的方法是P.526带刀刃边缘,P.1812和疏松楔形,平均误差为-5至+3分贝,散出约9分贝;P.1546是最悲观的(来自科斯塔,拉巴纳尔·拉米雷斯和PETOOL站附近陡坡地),记住它们服务于宽角的推进器和双向计算(救援所反映出波).
- 要进入遥远的管道, 你需要弗雷斯内尔。 如果管道开始于地平线以外,信号通过对障碍的疏导而来,直到开始;从1.3.2开始程序计算(Prevision Manual,§10之三). 会议:Rohde & Schwarz (2023年) 注意到高通道沿线的站台经常无法入站,而靠近终点站的站台是.
- 条件变化很快。 理论已经存在,但条件在分数上有所变化,没有预报系统能实时取出数据:GFS每6小时出出一次,时间跨度和0.25°,预报可以在短时间内失去价值. 会议:Bray(QST,1961年11月)测量100多英里的小时中位波动约为±7分贝;管道随大气时间移动(Rohde & Schwarz);我们的QSO登记号29/12/2021-2/1/2022显示开放在数小时内增长和下降。
- 目前最好的播报仍然是DX集群-PSK Reporter网络. 要知道现在会发生什么,群集点,PSK Reporter(和WSPR)击败了任何模式:它们是措施. 预报说看哪里,看能持续多久;广告说那里有. 这个程序将点和预测放在同一个地图上.

## 2. 目的

这个想法是第三个指数,由LIVETROPOVHF本身从一个天气模型的垂直剖面开始计算,与赫本和 F5LEN 并列,而不是取而代之. 今天,程序读取了他们的地图:一个索引还会说,为什么有打开(管道的量和厚度,被困的最小波段),它可能发生在程序已经收集的斑点上。

- 您可以给出什么: 管道每点和小时的概率, 基础和顶部的共享, 厚度, 最小频率被困, 沿着一条路径, 路由的一小部分 在一个管道内。
- 无法给出的:全球模型以0.25°不解的薄通管(几下十米)和从GHz上起作用的海上蒸发管.
- 第一个实用目标:欧洲144和432MHz,对DX集群点,PSK Reporter和当地解码进行核查.

## 3. 基础物理学

一切从反射开始 N在每一个剖面级别上计算:通道是修改后的反应M会减少攀升的地方,也就是dN/dh跌至−157 N/km以下的地方([ITU-R P.453-13](https://www.itu.int/dms_pubrec/itu-r/rec/p/R-REC-P.453-13-201712-S!!PDF-E.pdf). [Lopez,ECMWF 2008](https://www.ecmwf.int/sites/default/files/elibrary/2008/10803-5-year-40km-resolution-global-climatology-super-refraction-ground-based-radar-meteorology.pdf).]).

活性(P和hPa,T在kelvin):

```math
N = 77,6\,\frac{P}{T} - 5,6\,\frac{e}{T} + 3,75\times10^{5}\,\frac{e}{T^{2}} \;\approx\; \frac{77,6}{T}\left(P + 4810\,\frac{e}{T}\right)
```

相对湿度H(%)和温度t(°C)的蒸汽压力,在−40至+50°C之间的水上:

```math
e = \frac{H\,e_s}{100}, \qquad e_s = 6,1121\,\exp\left[\left(18,678 - \frac{t}{234,5}\right)\frac{t}{257,14 + t}\right]
```

改良回活性(h以公里为单位,或0.157-z以公尺为单位)和管道标准:

```math
M = N + 157\,h, \qquad \frac{dM}{dh} < 0 \iff \frac{dN}{dh} < -157\ \mathrm{N/km}
```

| dN/dh (N/km) (中文(简体)). | 条例 | 144兆赫的影响 |
| 0 个 | 子违反 | 减少流动率 |
| 从 0 到 - 79 | 普通( 标准约为- 40) | 等效半径的无线电视平面 |
| 从-79到-157 | 超级折射 | 长流"太好" |
| 15岁以下 | 管道( 绑住) | 被困信号,DX超过1000公里 |

如何从压力水平的模型中提取出N:对于每个水平,你取取T,相对湿度和地潜力高度,你计算N和M,然后计算相邻水平之间的梯度. 地下水平应被丢弃(阿尔卑斯山上1000 hPa在地下).

最小被困频率:相较于其厚度,管道只引导波段相当短. Hepburn发布一个表厚度~最小有用频率([DX Info Centre](https://www.dxinfocentre.com/propagation/luf.htm)]);这是一个软限制,在软限制下信号会逐渐下降.

|  91 m  | 464兆赫 |
|  122 m  | 276兆赫 |

在甚高频范围(通常为120-300米)中,表值遵循了恒定定律;低于100米的公式低估了高达30-40%的频率。 自行调整(不是赫本发布的公式),f为MHz和d为米:

```math
f_{min} \approx \frac{3,3\times10^{5}}{d^{3/2}} \ \mathrm{MHz} \quad\Rightarrow\quad d_{144} \approx 175\ \mathrm{m}, \quad d_{432} \approx 85\ \mathrm{m}
```

基本上,对于2米,管道往往至少170-180米,对于70厘米,大约一半。 在网上流通的公式为:QQmax = 0.014 = d^1.5,来源于克耳(1951, 第1章, eq. 18)并用QQ 以公分和站立形式有效,为M直线掉入的通路:这些单位给出了约2米180米和约70厘米89米的通路,这是由它产生的赫本表的同值. Kerr警告说,这不是一网割断:即使波浪也持续了好几次会遭受管道的伤害,一种"失去"一点的方式即使有站台出管道也能改善接待. 一项2019 IEEE Access研究证实,古典方法(Kerr,Kukushkin)没有描述真切([Shi等2019](https://doaj.org/article/d431fc16b2104524860927ac92dc1c53)]):阈值应作指示用,而不应作墙.

## 6. 程序实用公式

除了N和M( Basic Physics section)之外,这些都用于从垂直剖面到点数再通过路径移动. 11月22日,对正式文本([ITU-R P.452-18](https://www.itu.int/dms_pubrec/itu-r/rec/p/R-REC-P.452-18-202310-I!!PDF-E.pdf),P.453-14,P.526-16,P.372-18])进行了审查,并在代码中作了更正:Troposcatter 190(不是190,1)的常数加上气体吸收量为: = 3克/立方米;α不低于-3,4(eq. 55a); 含有: = 7.5 + 2.5= (eq. 9a)的管道气体; 整个球面地上的排出量(eq. 23-37):平均海面,高度功能,极限为2 + 20 log K,在光学流下插入; P.453-14(eq. 9)的蒸气饱和压为:用EF来取代Magnus的旧式。 Rumore P.372-18:表1和银河对应;人工噪声曲线高达250MHz,银河高达约100MHz,在程序之上延伸出相同的定律.

1. 联合国 相位介于两种相位(h以千米为单位,M以单位为M):

```math
\frac{dM}{dh}\Big|_{i} = \frac{M_{i+1} - M_{i}}{h_{i+1} - h_{i}}, \qquad \text{condotto se } \frac{dM}{dh} < 0
```

2. 联合国 接通强度和厚度:厚度d = 上-基(用于土壤管道,接通基 = 土壤);强度为基与上之间M的不足.

```math
d = h_{cima} - h_{base}, \qquad \Delta M = M_{base} - M_{min}
```

3个 地半径等同因子(P.452-18,eq. 5和6a), with N = 第1千米中平均N下降,为正数,以N/km:

```math
k_{50} = \frac{157}{157 - \Delta N}, \qquad a_e = k_{50}\cdot 6371\ \mathrm{km}
```

随着QQN = 40,您有大约 4/3 k (标准大气); QQN 接近 157 k 窗帘无限,即地球收音机变得平平:这是管道的起步.

4.四. 高天线(h米)的辐射地平线,半径相当于以公里计的:

```math
d_{oriz} \approx \sqrt{2\,a_e\,h/1000}\ \ \mathrm{km}\quad(\text{con } k = 4/3:\ d \approx 4,12\sqrt{h})
```

5 (韩语). 纬度通路概率(P452-18,eq. 2),时间百分比;__=路线中心纬度,μ1和μ4考虑其从海面上走多远:

```math
\beta_0 = 10^{\,-0,015|\varphi| + 1,67}\ \mu_1\,\mu_4\ \%\qquad (|\varphi| \le 70^\circ)
```

41°时 N,全取自海平面(μ1 = μ4 = 1),给出的时间约为11%:是气候学基础,作为参考值有用,预期指数与之不同.

6. 国家 轨迹散射器的损失(P.452-18, eq. 45;f in MHz, d in km, 在Mrrad的路径角度, N0 在路线中心地活性):

```math
L_{bs} = 190 + L_f + 20\log_{10} d + 0,573\,\theta - 0,15\,N_0 + L_c + A_g - 10,1\left[-\log_{10}(p/50)\right]^{0,7}
```

```math
L_f = 25\log_{10} f - 2,5\left[\log_{10}(f/2)\right]^2
```

−0,15 → N0 一词说明了湿空气为什么也会帮助没有通气管:50个额外的N单位比损失还少7.5分贝. LIVETROPOVHF已经使用 G3YGF 版本的散失.

7. 联合国 管道损耗(P.452-18, eq. 46-51):接合的固定损耗外加角毫平方根的减值,随频率的立方根而增生(f in GHz, a\_e in km):

```math
L_{ba} = A_f + A_d(p) + A_g, \qquad \gamma_d = 5\times10^{-5}\,a_e\,f^{1/3}\ \ \mathrm{dB/mrad}
```
