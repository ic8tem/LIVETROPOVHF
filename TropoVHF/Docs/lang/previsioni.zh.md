## 4. 索引和颜色

对于介于两个级别之间的每一层,程序将N的下降与Bean和Dutton [5] 的表 6.5的阈值进行比较:例如1000至850 hPa之间的下降可达60 N/km是正常的,超过100 N/km是超折射. 超反射层值10至15分贝的增益;根据M. 强风到地的不足,能将波段从20至25分贝的管道,高限层和高CAPE减少增益,因为它们去除或分解出地层[5,§ 4.4].

颜色是 dB 中的估计增益,所有主题的固定比例均匀:

| 增益 | 颜色 | 含义 |

| 7-10分贝 | 蓝色 | 渐变于正态 |
| 10-13分贝 | 绿色 | 超反射层 |
| 13-16分贝 | 黄色 | 强地层,但没有带状管 |
| 16-18.5分贝 | 橙红色 | 非常强的地层或太薄的管道 |
| 18,5-21分贝 | 红色 | 管道陷阱带 |
| 从21分贝 | 紫色 | 强而深的管道 |
