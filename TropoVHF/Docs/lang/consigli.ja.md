# オペレータのためのヒント

> イタリア語による自動翻訳: 疑わしい場合はイタリア語ガイドの価値があります。

駅作業のタブ予測を使用する実用的な表示。 リスニングを交換しない: 予測は、それが見栄えが最もよくある場所、ラジオはそこにいるかどうかを言います。

## 開始前

1. 土地主を8文字または10文字に書き込むと、土のシェアは土壌モデルのコペルニクスGLO-30と地上のアンテナの高さから来ます。 4文字または6文字で海上のアンテナのクォータは必須です。
2. 使用される頻度にブームの実際の長さおよびケーブルの損失を測定して下さい: ケーブルの2dBsはより短いアンテナとしてよいです。
3. 受信機の環境(市、住宅、農村、静かな農村)を選択します。 市では、144 MHz の人工的な騒音は受信機の多くを超過できます: 頻繁に最初の限界です。
4. 計算ログをオンにします: 結果が異様な場合、理由があります。

## 地図を読む

- 色を最初に見れば、ライン。 黄色は強い層を意味しますが、バンドのためのダクトはありません。 導かれる赤と紫の平均。
- 同時にバンドを変更:多くの場合、コンジットは432または1296 MHzで、144 MHzでなく、2 mはコンジットを必要とするためです。
- 滑走時間:地面ダクトは夜と夜明けに成長し、日と風で午後に休みます。 海に抗サイクロンも去る日。
- 抗サイクロンが立っているイソバレスショー。高度の空気が温暖である逆の曲線。 ゲインが圧力よりもインバージョンが続く場合は、地面に近い層をカウントします。
- AlpsとApenninesは、低水路を中断します:山の範囲に対して終わる色付きの領域は通常、それを交差しません。

## カウントする気象状況

ARRLハンドブック(19.4.3)とNBSの研究の経験から:

- Slow anticyclones:熱を低下させ、500と3000のメートル間の反転を形成する空気。 それらは最も広範囲のダクトであり、さらに数日間続きます。 北半球では、最高のルートは高圧の中心の南です。
- 夕方と朝: 土が冷やすときにダクトを強化します。日の出と日没の反転は20dBまで価値があります。
- 放射線反転(遅いと穏やかな土地、乾燥空気、谷):彼らは信号を改善しますが、ほとんど真の水路を行います。
- 暖かい前部の前で、数百キロのために、条件はよくあります。冷たい額の後ろに逆が強く、不安定であり、額に平行に見える方が良いです。
- 日没後、海岸沿いの大地の風:地上の新鮮な空気と200〜300mの熱風、また海岸に沿って800キロ以上伸びました。
- フォーン(アルプスにも): 冷気や雪の多い土壌に落ちる熱く乾燥した空気。
- Scirocco:新鮮な地中海と湿った地中海の上にサハラから熱く乾燥した空気。 強力な反転、マイクロ波で1500キロを超えるレコードを与えました。
- 天道、冷たい前部および強い風は層を壊します。

## リンクの前に

1. 対応するロケータ(マップをクリックするか、書き込む)を置き、信号を計算します。
2. 創設層を読んで下さい: ルート、覆われた地面、層の中の地面の継続性。 被扶養者の土地を上回らない海での水路は少ない。
3. アンテナが内側、または水路の下にあるかどうかを見てください。 信号の上部のはるかに上にあるアンテナから、ほとんどが間違っています。
4. 方法のしきい値でS / Nを比較します。SSBが足りない場合、 FT8 は20dB未満で十分です。
5. 予報が良いが、治療サイレントの場合は、少しを側面に指すようにしてください。ダクトは最大円に移動することができます。
6. ルートが山々の島(Sardinia、Corsica)を交差させる場合は、Bocche di Bonifacioなど、無料の海に向かっていくつかの度を試してみてください。狭い車線の強い風で少しになります。 予測マニュアルの深さでは、§10のキネ。

## オープニング中

- UTC、名前、ロケータ、バンド、方法、レポート:モデルをチェックする必要があるデータです。
- ハイバンドのビーコンをチェック:ダクトがそこにあることを実現する最速の方法です。
- 山を横断するルートでは、夏の午後を捨てないでください。レイヤーが一般的なボリュームの共有まで削除された場合、troposcatterは強化されます(強い兆候が、急激に蒸発します)。 計算は、ライン«Troposcatter午後»でそれを信号します。 予測マニュアル、§8 ter。
- FT8 およびクラスターでは、プログラムは広告を収集し、それ自体から解読します。 432 および 1296 MHz のオペレータレポートは不可欠です。

## 開催限度額

> 「禁止は一般化できませんが、局所形態に関連して研究されています。」 — DF5AI 、 IK3XTV で報告

地図は条件が好ましいところを言います。そのルートでは、実際の地上の計算ポイントがカウントされます。

- GFS には数百メートルしか離れていません。薄いバージョンは見られないと推定されています(二重計算 A と B)。 地上では、GFS は、より細かいモデルのダクトの約半分を参照してください。
- 予測は最初の24〜48時間でより信頼性が高く、トレンド表示ではありません。
- 状況を比較するために信号値が使用されます。 実質と比較して5〜10dBの廃棄が正常です。
- 天道、冷たい前部および強い風はパターン沈殿物の前に層を壊します。
