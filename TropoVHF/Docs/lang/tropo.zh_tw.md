# 如何在 144 MHz 及以後形成拖線

## 1. 發生的地方:對流層

對流層是大氣層的最低層,最高可達10-12千米. 電流計數主要為前3公里:水蒸發和倒置, 在正常情況下,氣溫下降,海拔約為每公里 [3] 6.5 °C. 另一方面,在一地層中,溫度隨高度而上升時,我們談論熱倒置:這是幾乎所有強特羅波開口的起點. [4]

甚高頻沒有被電離層反映為高頻(鹽分和零星的,有其他小時和其他相距 [5]): 超過地平線的,只有大氣層將其彎曲到地上或將其擴散出地平線時才會出現.

## 2. 折射和折射 N

無線電波會透過空氣彎曲 空氣折射指數與另一個。 指數n非常接近1,因此使用反應N,即n−1乘以一百萬 [11]:

```math
N = (n - 1) \cdot 10^{6} = \frac{77,6}{T} \left( P + 4810 \, \frac{e}{T} \right)
```

與P的hPa壓力,T的kelvin溫度和hPa的水蒸汽壓力相伴. N土壤通常為300–400. 第二個術語,即蒸汽,重量很大:因此溼度和 [3] [11] 溫度一樣多.

彎曲波的不是N值,而是隨著配額,梯度dN/dh的變化:

| dN/dh (N/km) (中文(簡體)). | 情況 | 對波的影響 |
| 0 個 | 分解 | 浪從地上移去,地平線更短 |
| 從 0 到 - 79 | 正常(標準-39) | 光向地平線:光學地平線的4/3左右 |
| 從-79到-157 | 超摺疊 | 波浪會彎曲更多,流速更高 |
| 小於 -157 個 | 內容 | 海浪像地球一樣彎曲 繼續被困住 |

−157 N/km的閾值是半徑曲率等於地球 [7] [11] 的點. 因此在計算 [6] 散射器時使用的"等同地束"為8497 km(實際半徑的4/3).

## 3. 倒置:tropo電動機

## 4. 地表和高管

管道是波浪在上邊緣(倒置)和地上或下邊緣 [7] 之間彈出而行走的地層:

- 地表管道:地上或出海. 低海拔站,特別是沿海站,直接入站.
- 高管:位於海拔高度上,例如500至2000米. 平原上的站可能沒有感覺,而山地上站或山地站的站入通道. 解釋跨越阿爾卑斯山或其他 [3] 解脫 [4] 的連結.

要進入管道,波應該開始幾乎是橫向的:地平線上的低天線,沒有相鄰的障礙. 在管道內部,衰減比自由空間要低得多,而距離達到1000至2000公里及更遠(例如伊比利亞半島、加那利群島和英國之間的接通,或斯堪的納維亞和俄羅斯南部之間的接通) [3] 。

## 6. 推土機散開

即使沒有倒置,對流層也不統一: 微小的溫度和溼度違規現象將一小部分能量擴散出地平線外. 它是一個一直存在的Troposferic散點,它允許連線300-800公里的好 [6] 站. 訊號弱而起伏;損失隨著擴散的角度而增加,即隨著距離和地平線上的障礙而增加:

```math
L_{s} = 21 + 10\, \theta_{s} + 10 \log f
```

## 8. 實際清單

1. 看看你所在區域 沿著你感興趣的方向 接下來的幾個小時
2. 請檢查access-eobare:高壓和寬等同位素在路徑上或旁邊.
3. 開啟熱倒置和T850 hPa:在路徑上方高度的熱空氣.
4. 更喜歡海上航道 晚上和早上
5. 如果你在山上, 想想高通道; 如果你在海岸, 在地表。
6. 先試試最高的樂隊(432,1296):先開放.
7. 用點和PSK Reporter進行校驗:同一方向的長行能確認通管.
