制御の下でラインは、圧力と可視領域の逆とのゲイン協定を与えます:ピアソン相関係数、- 1〜+1。 ダクトは、多くの場合、抗サイクロン(熱を低下させ、逆を形成する空気)で生まれますので、圧力との肯定的な合意は正常です。 しかし、同じ抗サイクロン内部では、ゲインは海、海岸、山間で多く変化します。 逆だけは十分ではありません:空気の上にある場合だけ波を曲げることはまた [5] をドライヤーです。 ラインは、色付きの領域を最もよく説明する、今、参照するのに役立ちます。 同じ比較はレジスタで書かれています。

## 6. 潜在的なパイプライン:二重計算

GFS レベルは 200 から 1000 m の範囲: 薄いバージョンが広がり、モデルは水路を見ません。 2つのレベルの間にNは正常な(40 N/km)を超過すれば、空気は安定します(3 K/kmの下の熱勾配)乾燥します(0.8の下の特定の湿気の比率)、プログラムは潜在的なダクトを考慮し、2つの方法でそれを計算します:

- カリキュラム A: 50mの集中された余分な低下すべて。

## 8 ter. 午後 troposcatter オーバーリリーフ (から 1.3.4)

IK3XTV は、ティエン( JN55 、アルプスを10キロで)から、400〜500キロの夏午後のドイツ南部で動作します。 視力が強いが、迅速かつ深いエバネセンスで。 著者は、「レンズの列車として並ぶ昆虫細胞」にそれらに起因しました。 観察が確認され、プログラムで採択された説明は、物理的にしっかりしたものです。

午後には、太陽が空気を吸い込み、限界層が2〜3kmに上がります。 湿った空気が上回って乾燥空気を満たします。屈折率(troposcatterを支配するサイズ)の濁度が最大です。 400～500kmで約2～3kmの経路の共通量に達すると、トロポスキャッターが補強されます。 これは午後の時間、高圧(沈黙した空、強い暖房)および急速な蒸発、拡散の典型的およびダクトのないを説明する。 導電性細胞はレンズとして機能しません:turbulenceを作り出し、そしてそれは信号を広げるrecastの層の上のturbulenceです。

予測を読むための結果:

- 地球上で最初の午後は、低ダクトと層のための最悪の時間ですが、山を越えてトロポスキャッターのためではありません。2つのことは別々に読むべきです。
- プログラムは既に2つのデータがあり、モデルによって提供される限界の層の高さと、結果のルートの共通ボリュームの共有(「Common Volume」を登録)。 彼らが閉じるとき、午後の山の御馳走は正常な大気の計算よりよく行くことができます;
- 1.3.4 からポイントポイントポイントの計算は考慮に入れます: 一般的なボリュームが地球上にある場合, ルートに沿って少なくとも 800 m の救済があります。, 太陽は 15° 以上であり、限界層は 800 m を超える, 層のリシャピングのトップ (モデル土壌率 + 限界層の高さ) は 500 m 以内です。 一般的なボリュームのベースから, tropostter は 3 dB; 500 と 1000 m の間で線形利益はゼロに落ちます. ライン«Troposcatter pomeridiano». ルートに沿って雪(モデルに応じて地面に少なくとも10cm、NOMADSからのGFSのOpen-MeteoまたはSNODの雪_変数)で補強は適用されません。雪には土壌が残っており、再形成された層は成長しません。 3 dB の値は暫定的であり、実際のリンクでキャリブレーションする必要があります。天気補正でオフになります。

```math
\hat{u}(x + \Delta x, p) = \hat{u}(x, p)\, e^{\, i \Delta x \left( \sqrt{k^2 - p^2} - k \right)}
```

- 標高ゼロの海と海岸平野の底部は、水平偏光のフレネルの係数、εc = εr - j·60·λ·σ(海 εr = 81 と σ = 5 S/m; 国 13 と 0.006 S/m)、経路の明確な角度でを反映しています。

```math
\Gamma_h = \frac{\sin\psi - \sqrt{\varepsilon_c - \cos^2\psi}}{\sin\psi + \sqrt{\varepsilon_c - \cos^2\psi}}
```

- 海の荒さは、ミラーとブラウンによると一貫した反射を低下させ、風から10 m(σh = 0,0051·U2)までの波の効果的な高さで:

```math
\rho = \exp\left[-2\left(k\,\sigma_h \sin\psi\right)^2\right]
```

- 海では、プロファイルMには、ニュートラル・ロジスミック・プロファイルを持つ蒸発ダクト(パラグラフ9 ter)が含まれています。

```math
M(z) = M_s + 0,125\left[(z - z_s) - \delta\,\ln\frac{z + z_0}{z_s + z_0}\right], \qquad z_0 = 1,5\times10^{-4}\ \mathrm{m}
```

海に10mのアンテナを試し、100〜300kmの標準大気を手に入れます。 δ = 10〜30メートルの蒸発ダクトは、1〜3dB〜144MHz、8〜37dB〜432MHz、21〜66dB〜1296MHzです。 水平偏光の144MHzでは、海は金属(|η|0,99以上、数十数度)と粗さがほとんど反映されます。新しい底は数dBの10分の1を変化させます。それは432MHzから数えられます。

限界:地球上の垂直プロファイルは、GFSレベルの残っているので、細いダクトは見えないままです。 手順への地面は近似しています。 ビームは6th以内に残っています。

## 12. アンテナ、信号および騒音

- Yagi DL6WU: 9.5 + 7.8・log10(boom/λ) を獲得 dBd (2.35 dB 二重ブーム、VHF コミュニケーション 3/1982) の [12] dBi のための 2.15 の DL6WU 対策。
- EIRP = 電源 − ケーブル + TX ゲイン。
- 信号受信 = EIRP - 予想損失 + RX - ケーブル RX. S-meter IARU: S9 = −93 dBm、単位ごとの6 dB。
- ITU-R P.372 [13]: galactic (Fa = 52 - 23 ログ f) 環境(都市、住宅、農村、静かな農村)または手書きのアンテナ温度に応じて、より人工的な。
- Tsys = Ta + Tpre + [290(Lc - 1) + 290(Fr - 1)・Lc)] / アンテナ(Friis式)の端末へのGpre。 1.3.5 から受信機の場所はアンテナ、固定変数の preamplifier が常にあります: 騒音番号 0.8 dB (Tpre = 59 K) および利益 20 dB。 ケーブル(ロスLc)とラジオがあり、基本的なノイズ番号Fr 6 dB。 1 dB のケーブルと無線入力が 1160 K から 12 K に低下します: 騒音は空、環境、プリアンプを決定します。 20dBのゲインはプログラムによって選ばれた典型的な値です。
- SSB、CW、 FT8 の各バンドのS / Nは、しきい値セットと比較して。
- 期間の確率(1.3.2から):時間内の蒸発は、予想される平均時間値の周りにS / Nの通常の分布です。 Bray(QST、1961年11月、p. 39、Norton 1959)の曲線では、約100マイルにわたって13,5dBの広さを与えます。つまり、平均よりも7dB前後で、100マイル(3,5dB〜50マイル)未満のほぼストレートに陥ります。 「固体」リンクは、予算から7dBかかります。 ±7 dB を ±2σ として取って下さい: σ = 160 の km の上の 3,4 dB の下の間隔に比例します。 期間が経過のしきい値を超えた確率は、

```math
P = \Phi\left(\frac{S/N - S/N_{soglia}}{\sigma}\right)
```

  Φの正常な配分機能を使って:余白0 dB = 50%、+3,4 dB = 84%、+7 dB (Brayの「固体」証拠) = 98%。 より大きいモデルの不確実性を含んでいません。
- デジタル方法:2500のS/N Hzは、事前情報(AP)なしで50%のデコードで測定されたしきい値と比較していました。 FT8 -21 dB および FT4 -17,5 dB 白色ノイズ; メカニズムが troposcatter が evanescence "disturbed 緯度媒体", FT8 -18,6 dB と FT4 -15,2 dB [21]. Q65 -15C −22,2 dB, Q65 -30B -24,8 dB, Q65 -60A -6 dB,6 dB dB dB,6 dB dB dB および -15,2 dB. 航空機では、ドップラーは、 Q65 -60A(1,7 Hz)の音を超えることができます。より良い30Bまたは15Cがあります。 JT65A - 25 dB [22] 。 解読AP(QSOの既知または終端の名前)は、 FT8 と1.5から2.6 dBの Q65 の約2dBの余分を与えます。 これは、 FT8 のためによく読まれているすべての«-24 dB»の値は、WSJT-Xの関係またはAPデコードの制限ではなく、50%でしきい値のために有効ではないので、しきい値を入力することはありません。 [24]

## 13. 応答とデータ時間

各計算は、GFSプロファイル(ネットワーク、分析、オープンメテオの制限のためのバッチ間の20秒の強制的な分割)、コペルニクスGLO-30地形(パンのダウンロードと、それぞれ15〜30 MB)、計算を測定します。 応答タイムラインはそれらを要約します。レジスタでは、行はTEMPIから始まります。 グリッドをアップグレードするとき、レジスタはGFSのレースも使用し、利用可能になったときにデータが古いかを報告します。

1.3.2 から ICON-2I、エージェンシー ItaliaMeteo と Arpae のモデルをイタリアで約 2.2 km、Open-Meteo (モデル italia_meteo_arpae_icon_2i、3 日) で選ぶことができます。 イタリアと近くの海だけをカバーし、GFS(1000、925、850、700、500 hPa)の低レベルが少ない。高度の水路はGFSよりも優れていませんが、微細な格子は、蒸発ダクトである2mの海岸、島、海をよく説明しています。 モデルが持っていない変数(strate limit、表面の温度...)は要求から自身を取除きます。 1.3.2 から自動ソースは NOMADS のみを使用します。 Open-Meteo は、NOMADS が応答せず、歴史的なケースのために機能します。 「自分自身でアップデート」ボックス(デフォルトで点灯)では、クリックせずに予測がダウンロードされます:オープン時に、NOMADS(レースの時刻から約5時間)の各新しいGFSレースで、可視領域がグリッドから4分の1以上で出ているとき。 ほとんどの試みでは、歴史的なケースでは絶対にありません。

Open-Meteoでのリクエストは、インターネットアドレスごとに1分、1時間あたりの制限があります。 ダウンロードしたプロファイルは、各ストロークとモデルのディスク(Dati/cache-gfs)に保存されます。同じレースで、6時間ごとに変更され、既にダウンロードしたポイントは再び尋ねません。 NOMADS と Open-Meteo から始まる自動ソースは、欠落点のみが機能します。 唯一の Open-Meteo で、時間制限または毎日がすぐに停止し、もう一度試してみると言います。 履歴ケースはキャッシュされません。

## 14. モデルの検証

予測は実際の接続と比較する必要があります。 計算ログは各番号を保持します。プログラム アーカイブは広告とデコードを保持します。 432 および 1296 MHz の場合、スポットが少ない場合は、オペレータからのレポートが必要です。誰が接続を行なったか、何時間、信号で。 測定された信号で予想されるゲインを比較すると、しきい値が移動されると言います。
