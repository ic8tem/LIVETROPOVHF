## 1. 彼が何をしているのか、彼が何をしているのか

GFS [1, 2] モデルの垂直温度と湿度プロファイルの予測は、レイヤーによる空気層の反応を導き出し、通常の大気と比較してどれだけの信号増加を推定します。 ルートでは、実際の地面(Copernicus GLO-30 [3])、分裂、troposcatter、ダクトおよび受信機の騒音を追加します。

それは測定ではありません:それは遠くのレベルの数百メートルの気象モデルで作られた推定です。 状況を比較するのに役立ちます(昨日よりも70センチメートルより良い2メートル、これはそれよりも優れています)、接続を保証するものではありません。 パラグラフ14は、証拠を検証する方法を説明しています。

## 9 クォーター。 対照的な空気海と低い海: アドリアティック (から 1.3.3)

電波は海底を感じません。空気と水面のコントラストを感じます。 海の温度は空気のそれに従っていかにすぐに決定するので深さの計算。

アドリアティックは低い海です。 平均深さは約250mですが、北部の盆地はほとんど100mを超え、トリエステの湾岸は25m未満で、南は1200mを超える。 水層が薄く暖まり、数日で冷やします。 3つの典型的な状況があります。

1. 春と初夏、好ましい。 アルパインとポ川の新鮮な水にしても、海はまだ寒く、それは平野やバルカンから熱く乾燥した空気に到着します。 冷たい水の上に熱風は海(適応パイプライン):イタリア、スロベニア、クロアチア間の開口部の古典的な状態です。
2. 秋と冬、ボラ、不利。 暖かみのある海の上にある冷気:低い層は不安定になり、混合し、ダクトは破壊します。
3. ボラの後、チャンス。 海が低いため、ボラは数日で数度冷ます。 熱い空気と抗サイクロンを入れば、空気海コントラストは強く、水路はいつもより強いです。

アドリアティックは、アペンニンとダイナリの間もクローズドなチャネルで、200 km未満の幅です。海層は終了し、軸線(Puglia-Venezia-Trieste、約700 km)に沿ったルートは、海、長いダクトに最適な状態です。

## 11 ビス。 パラボリック式(1.3.1から)

パラボリック式ラインは、ダクト(PETOOL;M. Lytaev、MITライセンスの波伝搬フレームワーク)のプロフェッショナルなプログラムとして作られた比較の4番目の計算です。レイヤーからのゲインを推定する代わりに、M修正されたGFS屈折率プロファイル内のFourier分岐法に沿って波を進め、各距離の予測ポイントから各距離に近づく。 GFS レベルは、潜在的なダクトの推定ジャンプに追加されます(A の計算、半層の 50 m)。 土壌コペルニクスGLO-30はステップに入ります(フィールドがヌルである地面の下で)、土壌は導体であり、アンテナのビームはゲインからの推定開口部を持つガウスです。 計算は、conduits、失った人、差異とアンテナの結合を見ます。彼は、割って追加されるtroposcatterを見ません。 次は«プロファイルのcheque»です:標準の大気と同じ、予想されたプロファイルで1つを削減します。

1.3.2から:

- プロパゲーターは広い角度で、自由空間の正確なフェーズです。

```math
\hat{u}(x + \Delta x, p) = \hat{u}(x, p)\, e^{\, i \Delta x \left( \sqrt{k^2 - p^2} - k \right)}
```

- 標高ゼロの海岸平野の海底は、水平偏光のフレネルの係数、εc = εr − j・60・λ・σ(海 εr = 81 と σ = 5 S/m; 国 13 と 0.006 S/m)、経路のクリアな角度でを反映しています。

```math
\Gamma_h = \frac{\sin\psi - \sqrt{\varepsilon_c - \cos^2\psi}}{\sin\psi + \sqrt{\varepsilon_c - \cos^2\psi}}
```

- 海の荒さは、ミラーとブラウンによると一貫した反射を低下させ、風から10 m(σh = 0,0051·U2)までの波の効果的な高さで:

```math
\rho = \exp\left[-2\left(k\,\sigma_h \sin\psi\right)^2\right]
```

- 海では、プロファイルMは、ニュートラル・ロジスミック・プロファイルを持つ蒸発ダクト(パラグラフ9 ter)を含みます。

```math
M(z) = M_s + 0,125\left[(z - z_s) - \delta\,\ln\frac{z + z_0}{z_s + z_0}\right], \qquad z_0 = 1,5\times10^{-4}\ \mathrm{m}
```

海に10mのアンテナを試し、100〜300kmの標準大気を手に入れます。 δ = 10〜30メートルの蒸発ダクトは、1〜3dB〜144MHz、8〜37dB〜432MHz、21〜66dB〜1296MHzです。 水平偏光の144MHzでは、海は金属(|η|0,99以上は数十数度)と粗さは少し数えられます。新しい底は数dBの10分の1を変化させます。それは432MHzから増加します。

限界:地球上の垂直プロファイルは、GFSレベルの残っているので、薄いダクトは見えないままです。 手順への地面は近似しています。 ビームは6th以内に残っています。

- Yagi DL6WU: 9.5 + 7.8・log10(boom/λ) を獲得 dBd (2.35 dB 二重ブーム、VHF コミュニケーション 3/1982) の [12] dBi のための 2.15 の DL6WU 対策。

- 信号受信 = EIRP - 予想損失 + RX - ケーブル RX. S-meter IARU: S9 = −93 dBm、単位ごとの6 dB。
- ITU-R P.372 [13]: galactic (Fa = 52 - 23 ログ f) 環境(都市、住宅、農村、静かな農村)、または手書きのアンテナ温度に応じて、より人工的な。

- SSB、CW、 FT8 の各バンドのS / Nは、しきい値セットと比較して。
- 期間の確率(1.3.2から):時間内の蒸発は、予想平均時間値の周りにS / Nの通常の分布です。 Bray(QST、1961年11月、p. 39、Norton 1959)の曲線では、約100マイルにわたって13.5dBの広さを与えます。つまり、平均よりも7dB前後で、ほぼ100マイル(3,5dB〜50マイル)未満に直下がります。 「固体」接続では、予算から7dBかかります。 ±7 dB を ±2σ として取って下さい: σ = 160 の km の上の 3,4 dB の下の間隔に比例します。 期間が経過のしきい値を超えた確率は、

```math
P = \Phi\left(\frac{S/N - S/N_{soglia}}{\sigma}\right)
```

  Φの正常な配分機能を使って:余白0 dB = 50%、+3,4 dB = 84%、+7 dB (Brayの「固体」証拠) = 98%。 より大きいモデルの不確実性を含んでいません。
- デジタル方法:2500のS/N Hzは、事前情報(AP)なしで50%のデコードで測定されたしきい値と比較していました。 FT8 -21 dB と FT4 -17,5 dB 白色ノイズ; メカニズムが troposcatter が evanescence "disturbed 緯度媒体", FT8 -18,6 dB と FT4 -15,2 dB [21]. Q65 -15C -22,2 dB, Q65 -30B -24,8 dB, Q65 -60A -6 dB,6 dB dB,6 dB dB,6 dB dB,6 dB dB dB,6 dB,6 dB. 航空機では、ドップラーは、 Q65 -60A(1,7 Hz)の音を上回ることができます。 30B または 15C よりも優れています。 JT65A - 25 dB [22] 。 解読AP(QSOの既知または終端の名前)は、 FT8 と1.5から2.6 dBの Q65 の約2dBの余分を与えます。 これは、 FT8 のためによく読まれているすべての«-24 dB»の値は、WSJT-Xの関係またはAPデコードの制限ではなく、50%でしきい値のために有効ではないので、しきい値を入力することはありません。 [24]

## 13. 応答とデータ時間

それぞれの計算は、GFSプロファイル(ネットワーク、分析、オープンメテオ制限のバッチ間の20秒の強制的な分割)、コペルニクスGLO-30地形(パンのダウンロードと、それぞれ15〜30 MB)、計算。 応答タイムラインはそれらを要約します。レジスタでは、行はTEMPIから始まります。 グリッドをアップグレードするとき、レジスタはGFSレースも使用して、利用可能になったときにデータが古いかを報告します。

1.3.2 から、ICON-2I、エージェンシー ItaliaMeteo と Arpae のモデルを約 2.2 km、Open-Meteo (モデル italia_meteo_arpae_icon_2i、3 日) で選ぶことができます。 イタリアと近くの海だけをカバーし、GFS(1000、925、850、700、500 hPa)の低レベルが少ない。高度のダクトはGFSよりも優れていませんが、微細な格子は、蒸発ダクトである2mの海岸、島、海についてよく説明しています。 モデルが持っていない変数(strate limit、表面の温度...)は要求から自身を取除きます。 1.3.2 から自動ソースは NOMADS のみを使用します。 Open-Meteo は NOMADS が応答せず、歴史的なケースのために機能します。 「自身でアップデート」ボックス(欠陥によって点灯)では、予測は非クリックです。開口部では、NOMADS(レースの時刻から約5時間)で、可視ゾーンがグリッドから4分の1以上出てきた場合、ほとんどの試みでは15分ごとに、歴史的なケースではなかった。

Open-Meteoでのリクエストは、インターネットアドレスごとに1分、1時間あたりの制限があります。 ダウンロードしたプロファイルは、各ストロークとモデルのディスク(Dati/cache-gfs)に保存されます。同じレースで、6時間ごとに変更され、既にダウンロードしたポイントは再び尋ねません。 NOMADS と Open-Meteo から始まる自動ソースは、欠落点のみで機能します。 唯一の Open-Meteo で、時間制限または毎日がすぐに停止し、もう一度試してみると言います。 履歴ケースはキャッシュされません。

## 14. モデルの検証

予測は実際の接続と比較する必要があります。 計算ログは各番号を保持します。プログラム アーカイブはスポットとデコードを保持します。 432 および 1296 MHz の場合、スポットが少ない場合は、オペレータからのレポートが必要です。誰が接続を行なったか、何度か、信号で。 測定された信号で予想されるゲインを比較すると、しきい値が移動されると言います。

P.452 および ITM で使用されるテストプログラムはソースコードツールのフォルダーにあります。ITU のテスト ケースは、ITU データを再配布しないため、別途ダウンロードする必要があります。
