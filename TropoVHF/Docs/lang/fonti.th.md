## 3. ฟิสิกส์พื้นฐาน

ทุกอย่างเริ่มต้นจากความผันผวน N. คํานวณที่แต่ละระดับโพรไฟล์: ท่อส่งข้อมูลที่ถูกแก้ไข M ลดลง, นั่นคือจุดที่ dN/dh ตกต่ํากว่า −157 N/km (ITU-R P.453-13](https://www.itu.int/dms_pubrec/itu-r/rec/p/R-REC-P.453-13-201712-S!!PDF-E.pdf), [Lopez, EMWF 2008 X1.](https://www.ecmwf.int/sites/default/files/elibrary/2008/10803-5-year-40km-resolution-global-climatology-super-refraction-ground-based-radar-meteorology.pdf)

Refactivity (P และใน hPA, T ใน Kelvin):

```math
N = 77,6\,\frac{P}{T} - 5,6\,\frac{e}{T} + 3,75\times10^{5}\,\frac{e}{T^{2}} \;\approx\; \frac{77,6}{T}\left(P + 4810\,\frac{e}{T}\right)
```

ความดันเนื้อร้ายจาก H (%) และอุณหภูมิ t (°C) เหนือน้ําระหว่าง −40 กับ +50 องศา

```math
e = \frac{H\,e_s}{100}, \qquad e_s = 6,1121\,\exp\left[\left(18,678 - \frac{t}{234,5}\right)\frac{t}{257,14 + t}\right]
```

การตอบสนองแก้ไข (h in km, หรือ 0.157 ez กับ z ในหน่วยเมตร) และระบบเชื่อมต่อ:

```math
M = N + 157\,h, \qquad \frac{dM}{dh} < 0 \iff \frac{dN}{dh} < -157\ \mathrm{N/km}
```

| dN/dh (N/km) | ตั้งค่าใหม่ | ผล กระทบ จาก 144 MHZ |
| 0 | การละเมิดสิทธิ์ | ลดอัตราการไหล |
| จาก 0 ถึง −79 | ปกติ (มาตรฐานเกี่ยวกับ −40) | ขอบฟ้าวิทยุมีรัศมีเท่ากับ 4/3 |
| จาก −79 ถึง −157 | การฝ่าฝืนมาก | การไหลอย่างยาวนาน "ดีเกินไป" |
| ด้านล่างนี้ −15 | ท่อ (ติดกับดัก) | ส่งสัญญาณ DX เกิน 1000 กม. |

วิธีแยก N ออกจากรุ่นที่ระดับความดัน: สําหรับแต่ละระดับ คุณใช้ T ความชื้นเชิงสัมพัทธ์ และความสูงภูมิศาสตร์ คุณคํานวณ N และ M แล้วเกรเดียนระหว่างระดับเพื่อนบ้าน ควร ทิ้ง ระดับ ใต้ พื้น ดิน (ที่ 1,000 hPA บน เทือก เขา แอ ลป์).

ความ ถี่ ที่ ติด ตัว น้อย ที่ สุด: ท่อ ส่ง น้ํา เพียง แต่ คลื่น สั้น ๆ เมื่อ เทียบ กับ ความ หนา ของ คลื่น. Hepburn ตีพิมพ์ความหนาของตาราง → ความถี่ที่มีประโยชน์น้อยที่สุด (DX India Central](https://www.dxinfocentre.com/propagation/luf.htm)); มันเป็นข้อจํากัดที่เบามาก ภายใต้การส่งสัญญาณค่อยๆลดลง

ในช่วงของ VHF (ประมาณ 120-300 เมตร) ค่าของตารางเป็นไปตามกฎเกี่ยวกับค่าคงที่; น้อยกว่า 100 m สูตรประเมินความถี่ต่ําไป 30-140% ปรับมันด้วยตัวเอง (ไม่ได้สูตรที่ตีพิมพ์โดย Hepburn), กับ f ใน MHz และ d ในเมตร:

```math
f_{min} \approx \frac{3,3\times10^{5}}{d^{3/2}} \ \mathrm{MHz} \quad\Rightarrow\quad d_{144} \approx 175\ \mathrm{m}, \quad d_{432} \approx 85\ \mathrm{m}
```

ในการปฏิบัติ: สําหรับ 2 m มันใช้ท่ออย่างน้อย 170-180 เมตร เพราะ 70 ซม. สูตรที่กระจายบนเน็ต, λmax = 0.014 สะกด d^1 มาจาก Ker (191, eq. 18) และใช้ได้กับ ในเซนติเมตร และยืน สําหรับท่อที่ M ตกเป็นเส้นตรง: หน่วยเหล่านี้ให้ค่าประมาณ 2 m 180 เมตร และประมาณ 70 ซม. เค อร์ เตือน ว่า มัน ไม่ ใช่ การ ตัด ตาข่าย แม้ แต่ คลื่น ที่ ยาว กว่า นั้น หลาย เท่า ก็ ทน ทุกข์ กับ ท่อ ส่ง น้ํา และ วิธี ที่ การ สูญ เสีย เล็ก น้อย อาจ ดี ขึ้น แม้ จะ มี สถานี ต่าง ๆ ออก มา จาก ท่อ. 2019 การศึกษาการเข้าถึง IEEE ยืนยันว่าวิธีการคลาสสิก (Kerr, Kakuchkin) ไม่ได้อธิบายการตัดจริง ([SHEEET al. 2019](https://doaj.org/article/d431fc16b2104524860927ac92dc1c53)): ธรณีประตูนี้ควรจะถูกใช้เป็นตัวบ่งชี้ ไม่ใช่เป็นกําแพง
