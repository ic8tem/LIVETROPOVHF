## 1. 提交人的住所

IC8TEM 觀測可以對工作進行框架化,在來源中可以找到反饋.

- 義大利地理學要求疏通. 與多爾薩爾站,Promontory站和離站後數十公里的島嶼相接相接,分流貢獻由主邊緣的弗雷斯內爾引數來計算出,而不只是平滑地. 會議:比較563 MHz的不規則地形(里約熱內盧,27個點在5至30公里之間),最好的方法是P.526帶刀刃邊緣,P.1812和疏鬆楔形,平均誤差為-5至+3分貝,散出約9分貝;P.1546是最悲觀的(來自科斯塔,拉巴納爾·拉米雷斯和PETOOL站附近陡坡地),記住它們服務於寬角的推進器和雙向計算(救援所反映出波).
- 要進入遙遠的管道, 你需要弗雷斯內爾。 如果管道開始於地平線以外,訊號透過對障礙的疏導而來,直到開始;從1.3.2開始程式計算(Prevision Manual,§10之三). 會議:Rohde & Schwarz (2023年) 注意到高通道沿線的站臺經常無法入站,而靠近終點站的站臺是.
- 條件變化很快。 理論已經存在,但條件在分數上有所變化,沒有預報系統能實時取出資料:GFS每6小時出出一次,時間跨度和0.25°,預報可以在短時間內失去價值. 會議:Bray(QST,1961年11月)測量100多英里的小時中位波動約為±7分貝;管道隨大氣時間移動(Rohde & Schwarz);我們的QSO登記號29/12/2021-2/1/2022顯示開放在數小時內增長和下降。
- 目前最好的播報仍然是DX叢集-PSK Reporter網路. 要知道現在會發生什麼,群集點,PSK Reporter(和WSPR)擊敗了任何模式:它們是措施. 預報說看哪裡,看能持續多久;廣告說那裡有. 這個程式將點和預測放在同一個地圖上.

## 2. 目的

這個想法是第三個指數,由LIVETROPOVHF本身從一個天氣模型的垂直剖面開始計算,與赫本和 F5LEN 並列,而不是取而代之. 今天,程式讀取了他們的地圖:一個索引還會說,為什麼有開啟(管道的量和厚度,被困的最小波段),它可能發生在程式已經收集的斑點上。

- 您可以給出什麼: 管道每點和小時的機率, 基礎和頂部的共享, 厚度, 最小頻率被困, 沿著一條路徑, 路由的一小部分 在一個管道內。
- 無法給出的:全球模型以0.25°不解的薄通管(幾下十米)和從GHz上起作用的海上蒸發管.
- 第一個實用目標:歐洲144和432MHz,對DX叢集點,PSK Reporter和當地解碼進行核查.

## 3. 基礎物理學

一切從反射開始 N在每一個剖面級別上計算:通道是修改後的反應M會減少攀升的地方,也就是dN/dh跌至−157 N/km以下的地方([ITU-R P.453-13](https://www.itu.int/dms_pubrec/itu-r/rec/p/R-REC-P.453-13-201712-S!!PDF-E.pdf). [Lopez,ECMWF 2008](https://www.ecmwf.int/sites/default/files/elibrary/2008/10803-5-year-40km-resolution-global-climatology-super-refraction-ground-based-radar-meteorology.pdf).]).

活性(P和hPa,T在kelvin):

```math
N = 77,6\,\frac{P}{T} - 5,6\,\frac{e}{T} + 3,75\times10^{5}\,\frac{e}{T^{2}} \;\approx\; \frac{77,6}{T}\left(P + 4810\,\frac{e}{T}\right)
```

相對溼度H(%)和溫度t(°C)的蒸汽壓力,在−40至+50°C之間的水上:

```math
e = \frac{H\,e_s}{100}, \qquad e_s = 6,1121\,\exp\left[\left(18,678 - \frac{t}{234,5}\right)\frac{t}{257,14 + t}\right]
```

改良回活性(h以公里為單位,或0.157-z以公尺為單位)和管道標準:

```math
M = N + 157\,h, \qquad \frac{dM}{dh} < 0 \iff \frac{dN}{dh} < -157\ \mathrm{N/km}
```

| dN/dh (N/km) (中文(簡體)). | 條例 | 144兆赫的影響 |
| 0 個 | 子違反 | 減少流動率 |
| 從 0 到 - 79 | 普通( 標準約為- 40) | 等效半徑的無線電視平面 |
| 從-79到-157 | 超級折射 | 長流"太好" |
| 15歲以下 | 管道( 綁住) | 被困訊號,DX超過1000公里 |

如何從壓力水平的模型中提取出N:對於每個水平,你取取T,相對溼度和地潛力高度,你計算N和M,然後計算相鄰水平之間的梯度. 地下水平應被丟棄(阿爾卑斯山上1000 hPa在地下).

最小被困頻率:相較於其厚度,管道只引導波段相當短. Hepburn釋出一個表厚度~最小有用頻率([DX Info Centre](https://www.dxinfocentre.com/propagation/luf.htm)]);這是一個軟限制,在軟限制下訊號會逐漸下降.

在甚高頻範圍(通常為120-300米)中,表值遵循了恆定定律;低於100米的公式低估了高達30-40%的頻率。 自行調整(不是赫本釋出的公式),f為MHz和d為米:

```math
f_{min} \approx \frac{3,3\times10^{5}}{d^{3/2}} \ \mathrm{MHz} \quad\Rightarrow\quad d_{144} \approx 175\ \mathrm{m}, \quad d_{432} \approx 85\ \mathrm{m}
```

基本上,對於2米,管道往往至少170-180米,對於70釐米,大約一半。 在網上流通的公式為:QQmax = 0.014 = d^1.5,來源於克耳(1951, 第1章, eq. 18)並用QQ 以公分和站立形式有效,為M直線掉入的通路:這些單位給出了約2米180米和約70釐米89米的通路,這是由它產生的赫本表的同值. Kerr警告說,這不是一網割斷:即使波浪也持續了好幾次會遭受管道的傷害,一種"失去"一點的方式即使有站臺出管道也能改善接待. 一項2019 IEEE Access研究證實,古典方法(Kerr,Kukushkin)沒有描述真切([Shi等2019](https://doaj.org/article/d431fc16b2104524860927ac92dc1c53)]):閾值應作指示用,而不應作牆.

## 6. 程式實用公式

除了N和M( Basic Physics section)之外,這些都用於從垂直剖面到點數再透過路徑移動. 11月22日,對正式文字([ITU-R P.452-18](https://www.itu.int/dms_pubrec/itu-r/rec/p/R-REC-P.452-18-202310-I!!PDF-E.pdf),P.453-14,P.526-16,P.372-18])進行了審查,並在程式碼中作了更正:Troposcatter 190(不是190,1)的常數加上氣體吸收量為: = 3克/立方米;α不低於-3,4(eq. 55a); 含有: = 7.5 + 2.5= (eq. 9a)的管道氣體; 整個球面地上的排出量(eq. 23-37):平均海面,高度功能,極限為2 + 20 log K,在光學流下插入; P.453-14(eq. 9)的蒸氣飽和壓為:用EF來取代Magnus的舊式。 Rumore P.372-18:表1和銀河對應;人工噪聲曲線高達250MHz,銀河高達約100MHz,在程式之上延伸出相同的定律.

1. 聯合國 相位介於兩種相位(h以千米為單位,M以單位為M):

```math
\frac{dM}{dh}\Big|_{i} = \frac{M_{i+1} - M_{i}}{h_{i+1} - h_{i}}, \qquad \text{condotto se } \frac{dM}{dh} < 0
```

2. 聯合國 接通強度和厚度:厚度d = 上-基(用於土壤管道,接通基 = 土壤);強度為基與上之間M的不足.

```math
d = h_{cima} - h_{base}, \qquad \Delta M = M_{base} - M_{min}
```

3個 地半徑等同因子(P.452-18,eq. 5和6a), with N = 第1千米中平均N下降,為正數,以N/km:

```math
k_{50} = \frac{157}{157 - \Delta N}, \qquad a_e = k_{50}\cdot 6371\ \mathrm{km}
```

隨著QQN = 40,您有大約 4/3 k (標準大氣); QQN 接近 157 k 窗簾無限,即地球收音機變得平平:這是管道的起步.

4.四. 高天線(h米)的輻射地平線,半徑相當於以公里計的:

```math
d_{oriz} \approx \sqrt{2\,a_e\,h/1000}\ \ \mathrm{km}\quad(\text{con } k = 4/3:\ d \approx 4,12\sqrt{h})
```

5 (韓語). 緯度通路機率(P452-18,eq. 2),時間百分比;__=路線中心緯度,μ1和μ4考慮其從海面上走多遠:

```math
\beta_0 = 10^{\,-0,015|\varphi| + 1,67}\ \mu_1\,\mu_4\ \%\qquad (|\varphi| \le 70^\circ)
```

41°時 N,全取自海平面(μ1 = μ4 = 1),給出的時間約為11%:是氣候學基礎,作為參考值有用,預期指數與之不同.

6. 國家 軌跡散射器的損失(P.452-18, eq. 45;f in MHz, d in km, 在Mrrad的路徑角度, N0 在路線中心地活性):

```math
L_{bs} = 190 + L_f + 20\log_{10} d + 0,573\,\theta - 0,15\,N_0 + L_c + A_g - 10,1\left[-\log_{10}(p/50)\right]^{0,7}
```

```math
L_f = 25\log_{10} f - 2,5\left[\log_{10}(f/2)\right]^2
```
