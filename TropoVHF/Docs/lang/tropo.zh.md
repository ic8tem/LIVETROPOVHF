## 1. 发生的地方:对流层

对流层是大气层的最低层,最高可达10-12千米. 电流计数主要为前3公里:水蒸发和倒置, 在正常情况下,气温下降,海拔约为每公里 [3] 6.5 °C. 另一方面,在一地层中,温度随高度而上升时,我们谈论热倒置:这是几乎所有强特罗波开口的起点. [4]

甚高频没有被电离层反映为高频(盐分和零星的,有其他小时和其他相距 [5]): 超过地平线的,只有大气层将其弯曲到地上或将其扩散出地平线时才会出现.

## 2. 折射和折射 N

无线电波会通过空气弯曲 空气折射指数与另一个。 指数n非常接近1,因此使用反应N,即n−1乘以一百万 [11]:

```math
N = (n - 1) \cdot 10^{6} = \frac{77,6}{T} \left( P + 4810 \, \frac{e}{T} \right)
```

与P的hPa压力,T的kelvin温度和hPa的水蒸汽压力相伴. N土壤通常为300–400. 第二个术语,即蒸汽,重量很大:因此湿度和 [3] [11] 温度一样多.

弯曲波的不是N值,而是随着配额,梯度dN/dh的变化:

| dN/dh (N/km) (中文(简体)). | 情况 | 对波的影响 |
| 0 个 | 分解 | 浪从地上移去,地平线更短 |
| 从 0 到 - 79 | 正常(标准-39) | 光向地平线:光学地平线的4/3左右 |
| 从-79到-157 | 超折叠 | 波浪会弯曲更多,流速更高 |
| 小于 -157 个 | 内容 | 海浪像地球一样弯曲 继续被困住 |

−157 N/km的阈值是半径曲率等于地球 [7] [11] 的点. 因此在计算 [6] 散射器时使用的"等同地束"为8497 km(实际半径的4/3).

## 4. 地表和高管

管道是波浪在上边缘(倒置)和地上或下边缘 [7] 之间弹出而行走的地层:

- 地表管道:地上或出海. 低海拔站,特别是沿海站,直接入站.
- 高管:位于海拔高度上,例如500至2000米. 平原上的站可能没有感觉,而山地上站或山地站的站入通道. 解释跨越阿尔卑斯山或其他 [3] 解脱 [4] 的链接.

要进入管道,波应该开始几乎是横向的:地平线上的低天线,没有相邻的障碍. 在管道内部,衰减比自由空间要低得多,而距离达到1000至2000公里及更远(例如伊比利亚半岛、加那利群岛和英国之间的接通,或斯堪的纳维亚和俄罗斯南部之间的接通) [3] 。


## 8. 实际清单

1. 看看你所在区域 沿着你感兴趣的方向 接下来的几个小时
2. 请检查access-eobare:高压和宽等同位素在路径上或旁边.
3. 开启热倒置和T850 hPa:在路径上方高度的热空气.
4. 更喜欢海上航道 晚上和早上
5. 如果你在山上, 想想高通道; 如果你在海岸, 在地表。
6. 先试试最高的乐队(432,1296):先开放.
7. 用点和PSK Reporter进行校验:同一方向的长行能确认通管.
