# 地図の建設

> イタリア語からの機械翻訳です。疑問がある場合はイタリア語版のガイドが優先します。

タブマップとスポットのマップが生まれます:地理的ベース、投影、ヘプバーンと F5LEN インデックスの平均、イソバレ、スポット、およびステーションのリスニング、レイヤーで重複します。 2026年11月9日 バージョン

## まとめ

- 地図は8つの層のプログラムによって、それぞれ [8] 箱設計されています。
- ベース:自然地球の海岸線と [9] の2つのレベルの境界線。 [10] 市場とアジマスの投影。
- 物理:反転、反応 N および勾配 dN/dh は、-157 N/km [3] [4] [7] [11] の鉛のしきい値です。
- Throatのインデックス: Hepburn [1] と F5LEN [2] のマップ、共通のグリッドと2つのソースの平均値の校正済み読み込み。
- Isobare:GFS [12] の圧力は、Open-Meteo [15] 、ライン4 hPa、HとLセンターを介して。
- スポット、リスニングステーション(常に見えるピンクラインのピンクサークルをダーク)、赤の個人デコード。
- 重複を読む:高圧、高ダクト、圧力降下、成長SNR、 [3] [4] [5] [13] [14] の山のルート。

## 2. 基本マップ

パブリックドメイン [9] の自然地球のベクトルデータ、パブリックドメインのコスト、境界線と土地が1:50百万規模で、拡大すると1:10万人。 ファイルはプログラムフォルダにある:オンラインマップサービスはありません。 テーマの色 クリア: ライトブルーの海 # E2ECF8 、ダークブルーの海岸、ライトグレーの境界。 テーマ 黒と夜では、ベースの色が暗くなり、他のテーマでは少し染めます。

## 3. 2つのプロジェクト

すべてのレイヤーは同じプロジェクション関数を通るので、それらは常に互いに整列されます。 2つの [10] の投射(λの経度、φの緯度、地球のRの光線):の間で選ぶ

市場。 ローカルコーナーや形状を保存します。 棒に向かって伸びる距離。 緯度±85°にカット

```math
x = R \cdot (\lambda - \lambda_{0})
y = R \cdot \ln \tan \left( \frac{\pi}{4} + \frac{\varphi}{2} \right)
```

Azimutale equidtanti があなたの正方形に集中しました。 中央(φ0、λ0)は、WWLの角の中心です。 中心から測定された距離と方向は真です。1200kmの駅は1200kmの規模で、北の角度はアンテナを指すための方程です。 ロケータを変更するとマップのリフォーカス。

```math
\cos c = \sin \varphi_{0} \sin \varphi + \cos \varphi_{0} \cos \varphi \cos (\lambda - \lambda_{0})
k = \frac{c}{\sin c}
x = R \cdot k \cdot \cos \varphi \sin (\lambda - \lambda_{0})
y = R \cdot k \cdot \left[ \cos \varphi_{0} \sin \varphi - \sin \varphi_{0} \cos \varphi \cos (\lambda - \lambda_{0}) \right]
```

AZMutaleでは、紙の直線(メリディアン、並列、正方形のエッジ)が湾曲するラインがカーブします。 そのため、すべての行が短いトレイトに分割され、各セクションがプロジェクションされ、トレイトが結合されます。 同じことは、トロポのインデックスとイソバへのエッジに適用されます。 中心の悪質へのポイントは明確な位置を持っていませんし、視界から残っています。

## 4. グリルロケーター、ズーム、移動

メイデンヘッドグリッドはプログラムによって設計されています: 20°×10°のフィールドと2つの大きな文字と中心、2°×1stの四角、および5′×2,5′の十分なズームサブクォラティで。 線は青く薄く、トポ指数を覆わない。

ポインタを中心とするホイール(マウスの下の点は定着)をズームし、ドラッグを移動し、ダブルクリックしてビュー全体に戻り、+キーと-キー、およびビュー全体のパーセンテージのキーに戻します。 細部はズームレンズに合います:より細かい海岸、サブスクエア、より厚い isobare ラベル。

## 5. なぜ反転が波を曲げるのか

低い大気では、温度は、通常約6.5 °C / kmで低下します。 屈折率は、温度と [3] の湿気の両方に依存し、それが地に波の曲がりと急激に変化し、さらに正常よりも到着します。 最も重要な層は、バージョン、ダクト、および対向セル [4] が形成される3 kmまでです。 水塊が [4] 反転の大きな領域を形成するので、海道は好ましいです。 [3]

測定するサイズは、屈折性N、すなわち(n − 1)・106 [11] です。

```math
N = \frac{77,6}{T} \left( P + 4810 \cdot \frac{e}{T} \right)
```

Tはケルビン、Pの圧力および蒸気圧力、hPaの両方の温度です。

共有 (dN/dh) で異なる N としてカウントします。 標準的な大気はおよそ-39 N/kmです;--79 N/kmまでの屈折は、超屈折に加えて、通常の考慮され、サブ反射 [7] の正の勾配と。 以下 −157 N/km 波は地球の湾曲よりも曲げられ、閉じ込められたままである:それは [11] (ダクタリング)ダクトです。 ヘップバーンと F5LEN マップが予測しようとする条件です。

## 6. tropo インデックス: 2 つのマップから平均

Hepburn と F5LEN タブは、コントロールデスクです。各ソースのページからダウンロードした画像を表示し、変更可能な予報時間とともに、凡例の参照ポイントと色をクリックすることで、読み取りをキャリブレーションします。 tropo インデックス層は、少なくとも 2 つの校正の 1 つがアクティブで完了するまで空のままです。

ヘップバーン。 Hepburn インデックスは、0 から 10 までの線形スケールで領域を折り畳むと、どのくらいの波が期待されるかを測定します。 0 は標準的な大気を意味し、スキャッターだけ; 1–2 の余白か弱い超反射; 3–4 のダクト区域との超反射; 索引はスキャッターのtropoを考慮に入れませんし、 [1] の山を見ません。 地図は6日間カバーします:最初の36時間、3時間のパス、その後6時間、毎日18 UTC [1] に更新されます。 開始データ(温度、湿度、圧力)は、カナダの気象サービス [1] のグローバルモデルから来ます。 [1]

F5LEN. ヨーロッパ F5LEN は+3から+192時間(+48までの3時間、+96までの各6、12)の31の地図を出版し、タイトルで有効な日付と時刻、右下の生産時間とクラスの凡例:Disturb、Normal、Weak、Good、Vy Strong、Duct [2] 。 F5LEN の世界の予測は、単位Nの空気屈折率によって計算され、3時間(約5日)の40ステップで、1日に4回更新されます。 地図のクリックは、平均値とその点のロケータを示しています。 [2]

採用情報 各予測ステップでは、プログラムが次のステップを実行します。

1. 排出。 2つの予測の画像は、実行可能の横にあるキャッシュでダウンロードされます。一度は、再設計ではなく、ソースを更新します。 最終バージョンの前に、Hepburn と F5LEN への許可が必要です。
2. 自動ジオリファレンス。 プログラムは、フレーム(同じ色の2つの水平線と2つの垂直線)を見つけ、Windows 10/11では、OCRがシステムに軸ラベル(54N、10W、0、5E...)に統合しました。 フレームの周りのストリップをカットし、それらを拡大し、手紙N / S / E / Wが最もラベルが落ちるラインを読んで保持していないときに両方の兆候をテストします。誤った読書が残っています。 ここからは、フレームと投影の種類(通常グリルやメルテーター)の極端なラ/ロンを得ることができます。 フレームがサイズを変えれば、極端に自分自身を保存し、それ自体を回復させます。 Mac と Linux では、OCR なしで、工場の処理や手書きのタブで有効です。 または、正当な軸を持たないマップの場合: 地図の各タイプ(Hepburn Europa、 F5LEN 世界的に...)は、キャリブレーションを持っています: 既知の座標を持ついくつかの制御点(メリディアンと並列の交差、認識可能な肋骨)は、そのソースで使用される投影で、緯度と経度にピクセルを接続します。 校正はプログラムの横にあるファイルであり、ソース変更の形式であれば再作成できます。
3. 色の読書。 各ピクセルは、ソースの凡例と比較して、最も近い数値に変換されます。 オリジナルの地図上に描かれたコスト、ライティング、グリッドは「データなし」として認識され、近くの値で埋められます。
4. 世界の格子。 各画像は、フレームが発見され、極端に知られると、地球上に置かれます。世界のどの時点でも値がそれをカバーする画像から派生しています。 より多くの地域が同じ点を覆うと、その時間がその選択から1.5 h以内である(程度あたりのピクセル以上)、その後、最も近い時間、その後、最も最近のレースです。 地図が灰色のベールを示す場所:「インデックス0」とは異なるデータはありません。 フレーム内部では、凡例色のないピクセルは0(通常の雰囲気)です。 海岸、境界線、ライティングは3ピクセル以内に最も近い色を見てジャンプします。
5. 同じ梯子。 Hepburn は既にスケール 0～10 [1]: 暗い背景 = 0 と 10 色の順番 (紫、青、水緑、ライム、黄色、オッチャー、オレンジ、赤、ピンク、ライトピンク) 1...10、ライラックを超えて。 F5LEN はクラス(Disturb、Normal、Minor、Wak、Good、Strong、Vy Strong、Duct) [2] を使用しますが、一部はHepburn色を正確に持っています: 弱い = 1, 強 = 5, 強 = 7, ダクト = 8; マイナーは 0.5 と グッド (緑) 3.5. F5LEN タブのスケールマルチプライヤーは、Hepburnと同等のようにセットを補正します。
6. 同じ時間。 3時間のステップで+0から+192 hにタイムバーがあります。 各ソースから取得する各ステップは、最も近い時間で有効な予測をします。 ソースがそのステップを持っていない場合、メディアは他のものだけを使用し、凡例はそれを示します。
7. メディア メディアボタンで各ポイントは価値があります (Hepburn + F5LEN) / 2; Hepburn または F5LEN で 2 つの予測が解約する場所を理解するのに便利です。
8. デッサン。 数値は、凡例のスケール(0青、2緑、4黄色、6オレンジ、8赤、10紫色)で色付けされ、グリッドの下にあるサンプリングとして提案されます。 0は透明で、きれいな基本マップが見えないので、一般的な透明度はボックスの横のカーソルで調整します。

スポットタブでは、ルートに沿ったインデックスは、2つのステーション間の最大円で10キロごとにグリッド値の選手権の平均です。

## 7. イソバレー

安定した圧力は [3] のトロープのために求められている最初の信号であり、 IK3XTV の分析されたアルプスを超えた接続は高い [4] 圧力でもありました。

1. データ。 NOAA [12] のグローバルモデルGFSから海面での圧力, 3°×3°のグリッド上の無料のOpen-Meteo [15] サービスを読みます (30°から72°まで) N、30°Wから48°Eまで、次の78時間。 プログラムは、モデルレースのように、起動時に6時間ごとにデータを更新します。
2. ライン。 イソバレは、4つのhPa(...1012、1016、1020...)ごとにグリッドから取得され、マーチングスクエア(マーチングスクエア)のアルゴリズムで、それらはわずかに丸みがあり、トラクトによって描画される。
3. センター ローカル最大値と最小値が H (青) と L (赤) と hPa の値をマークします。
4. ラベル。 地図のカラー背景に、それぞれのイソバラに値が現れ、サンプリングよりも読みやすくなります。

エリアとステップ。 データは、あなたが見ている領域でダウンロードされます, 25%によって拡大, からステップで 1st から 20° まで選択され 400 ポイント以下を維持します (オープン・メテオは、リクエストとしてすべてのポイントをカウントします: 600 1分あたり, 5000 1時間): 既にプログラムをダウンロードした領域のマップを拡張または移動することにより、最も密なリロード, ほとんどの10分; 更新が以前のデータが残った場合、3分後に再び試みます. 世界中のどこからでも、そばや気温が働きます。

温度。 同じように要求温度を2 mに、925 hPaおよび850 hPaに持って下さい。 LA0BY は、温度マップ(900〜3000m)で UA6 に22 / 11 / 2018のイベントが見られることを示していますが、Hepburn [3] の予測ではなかった。 DF5AI と DK5YA は、 [5] の反転を認識するために垂直温度プロファイルを使用する。 このためには2つの層があります:

- 温度 850 hPa: isoterme は 4 °C 毎に扱います(ゼロの上の赤、ゼロの青)。
- 熱間反転: 925 または 850 hPa の空気が 2 m よりも暖かく、より強烈な、より多くの反転が強いオレンジ色のサンプリング。 グラウンド [3] [11] に波を曲げてトロポ指数と比較し、予報が気象基準を持っている場合は、イソバレが示す物理的条件です。

## 8. スポット・駅

スポット。 既知のポジションを持つ各スポットは、2つのステーション間の最大円の線で、セクションに分割し、プロジェクションされます。 メルトーレでは、それがセンターから始まると、わずかに曲線表示されます。 通常のスポットにフルブルーライン、エア散布(<AS>、<ACS>、またはコメントの「エア散布」)、各駅のボール、線の下にあるライトはサンプリングから切り離します。 選択されたスポットは、最後に2つの名前でデザインされています。

リスニング。 各PSKReporter [16] 受信ステーションは濃いピンクの空の円です。 各開始から完全にピンクラインがネットワークにデコードされ、送信された場所へ、常にクリックせずに表示され、名前は常に書かれています。 円を選ぶと、その線が太くなります。 スポットとリスニングは、リストで選択したバンドと範囲のみを表示:マップの変更は空であり、新しいバンドのために既に収集したデータと再設計されます。

わたしによって決定される。 WSJT-X、JTDX、MSHV(UDP経由のレシート)でデコードする各ステーションは、QTHから駅まで、ボールや指名でフルラインです。 予測との最も直接比較です: あなたの受信機が今実際に来る場所を示します。

45°で点在するライラックの正方形は何ですか。 QTHの関心から離れたトラフィックは、伝搬が開いている場所を理解します, しかし、そのライン, 数百キロの長さと多くの場合、10秒, マップをカバーし、あなたのためのカウントを隠します: あなたの駅から悪用することができます開口部. そのため、選択した王冠を超えて、プログラムは行を描画しませんが、関与するステーションのロケータスクエア(2°×1°)を着色します。 その結果は、«active Zones»のマップです。多くの近隣のライラックスクエアが現れ、あなたが直接気にしない場合でも、水路や開口部があります。 領域があなたに向かって広まっている場合は、その方向にアンテナを指す信号です。 45°ダッシュボードでは、トロポのインデックスとグリッドで表示できるので、予測(ボトムカラー)と実際のトラフィック(イラスト)を一目で比較できます。 QTHの正方形は、出発点と遠距離ではないため、決して色付けしません。 王冠を越えている四角だけは色付けされます: 王冠によって交差される正方形、または内部は2つの場所の1つがあっても放します。 ラインを見るには、ボックスをオフにするか、より大きなクラウンを選択します。

地図上で何が起きているのかを決める基準と、破棄されたものについては、ドキュメント1、セクション11 terで説明しています。

## 10. 重複を読む方法

- 高圧 + 高指数 + 色の領域に沿ってスポット: 開口部はそこにあり、計画されている1つです。 その方向に呼ぶ時間です。
- 高いインデックスが点在していない: または誰もアクティブにされていない、または予測があまりにも楽観的です。 リスニング層は区別するのに役立ちます: エリアに受信機があり、何も感じた場合、第二の仮説はより可能性が高いです。
- 色の領域の外側のロングスポット:表面予測が見えないハイダクト、LA- UA6 [3] イベント; またはフィルタからエスケープされた別の伝搬(例えば、タグなしのEスラブ)。 DF5AI と DK5YA は、トロポとEスプラディックを区別します。また、時間から区別します。 拡散Eスプラディックと一緒に生まれ、終わる開口部は、ほとんど [5] トロポです。
- Hepburn と F5LEN の不一致: ボタンで 2 つのソースを比較し、実際のスポットが落ちる場所を確認します。
- 圧力ダウン: G4MCU は、圧力が低下するまで SK6VHF ビーコンの開口部に続いて、1012 hPaは終了イベント [13] を検討しました。 タイムバーをスクロールすることで、イソバを観察:高圧が引き出すと、開口部はおそらくそれに従います。
- 立ち上がる信号: KP4MD の144MHzのWSPR研究では、Hepburnが改善を予測し、予測が [14] を取ったときに低下したウィンドウで信号/ノイズ比が右に増加しました。 同じパスが成長すると、開口部が形成されます。
- マウンテンパス:インデックスは [1] の救済を考慮に入れませんが、アルプスを超えての接続は、大気の重力 [4] の対比セルと波のおかげで存在し、 LA0BY はヘプバーンがそれを予測することなく、山を介して9Aと S5 働いた [3] 。

## 11. オープンポイント

- Hepburn と F5LEN の権限で、プログラムのマップを使用します。
- 変換係数の較正 F5LEN → スケール 0～10.
- 任意の種類のマップの制御ポイントの較正、ソースがグラフィックを変更した場合を再作成する。
- GFSから温度(高度850hPa)でのオプションルート。
