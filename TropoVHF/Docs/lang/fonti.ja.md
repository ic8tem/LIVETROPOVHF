# ソースと式

> イタリア語による自動翻訳: 疑わしい場合はイタリア語ガイドの価値があります。

LIVETROPOVHFトロポ予報(20〜21 11月2026)のソースの作業コレクション: 基本的な物理、利用可能なデータ、公開されたインデックス、式、ラジオアマチュアの経験、検証、決定。 式はLaTeX、(1)、(2)、...、および括弧内の番号でリコールするテキストで番号付けられます。 予測マニュアルは、プログラムがそれらを使用する方法について説明します。


## 1. 著者の敷地

IC8TEM は、ソースで見つかったフィードバックで、作業をフレーム化します。

- イタリアの地理は、diffraction を呼び出します。 リッジ、promontory、そして島はステーションから数千キロのキロメートルを占めるので、差分の貢献は、スムーズな土地だけでなく、メインエッジのFresnelパラメータで計算する必要があります。 会議: 563 MHzで不規則な地形で比較 (リオ・デ・ジャネイロ, 5 と 30 km の間の 27 ポイント), 最良の方法は、ブレードのエッジと P.526 であった, P.1812 と diffractive ウェッジ, 平均誤差 間の −5 と +3 dB と約分散 9 dB; P.1546 は、最も pessimist (コスタから, ラバンダル・ラミレレスと ペットの周辺斜面は、それらが広い方向に反映される (OOLO) は、彼らは、その角度を思い出します。
- 遠くの水路に入るには、Fresnelが必要です。 conduit が horizon を越えると、その開始まで障害を diffraction で信号が来る; 1.3.2 からプログラムはそれを計算します(予測のマニュアル、§ 10 ter)。 会議:ローデ&シュワルツ(2023)は、多くの場合、ハイダクトに沿って駅が入るのに失敗し、それらが端に近いがはい。
- 条件はすぐに変わります。 理論はそこにありますが、条件は数分で変化し、予測システムはリアルタイムでデータを取りません。 GFSは6時間ごとに発生し、時間スパンと0.25°、予測は短時間で値を失うことができます。 会議:Bray(QST、1961年11月)は、100マイルを超える約±7 dBのタイムリーなメディアンの変動の測定。ダクトは大気時間(ロード&シュワルツ)で移動します。29/12/2021–2/1/2022のQSOレジスタは、時間内で成長し、落下を示しています。
- DXクラスター–PSKReporterネットワークが残っているのがベストです。 今何が起こるかを知るために、クラスタースポット、PSKReporter(およびWSPR)はどんなパターンにも打ち勝つ:それらは対策です。 予測は、それが続くことができるどのくらいの時間と見る場所と言います。 コマーシャルは、そこにいるかどうかを言います。 このプログラムでは、同じマップにスポットと予測を入れています。

## 2. ミッション

アイデアは、天候モデルの垂直プロファイルから始まるLIVETROPOVHF自体によって計算された3番目のインデックスで、それらを置き換える代わりにHepburnと F5LEN に追加されます。 今日、プログラムは既に準備が整ったマップを読み込みます: インデックスは、*why* が開いている(コンジット、最小限のバンドトラップの厚さ)、プログラムが既に収集するスポットで発生することがあります。

- あなたが与えることができるもの:ポイントと1時間あたりの水路の確率、ベースとトップの共有、厚さ、最小周波数のトラップ、および通路の円筒内のルートの割合に沿って。
- 与えることができないもの:0.25°のグローバルモデルが解決しない薄いダクト(数メートル未満)と、 蒸発ダクト の海、 GHz からすべて上で提供する。
- 最初に実用的な目的: DX のクラスターの点、PSKReporter およびローカル解読の検証を用いるヨーロッパの 144 および 432 の MHz 。

## 3. 基礎物理学

すべてが屈折から始まります 各プロファイルレベルで計算されるN:コンジットは、修正されたリアクティブMが上昇する場所であり、dN/dhが-157 N/km([ITU-R P.453-13](https://www.itu.int/dms_pubrec/itu-r/rec/p/R-REC-P.453-13-201712-S!!PDF-E.pdf)、[Lopez、ECMWF 2008](https://www.ecmwf.int/sites/default/files/elibrary/2008/10803-5-year-40km-resolution-global-climatology-super-refraction-ground-based-radar-meteorology.pdf))以下に該当する場所です。

屈折率(PおよびhPa、ケルビンのT):

```math
N = 77,6\,\frac{P}{T} - 5,6\,\frac{e}{T} + 3,75\times10^{5}\,\frac{e}{T^{2}} \;\approx\; \frac{77,6}{T}\left(P + 4810\,\frac{e}{T}\right)
```

相対湿度H (%)および温度t (°C)からの蒸気圧力、- 40と+50 °C間の水上:

```math
e = \frac{H\,e_s}{100}, \qquad e_s = 6,1121\,\exp\left[\left(18,678 - \frac{t}{234,5}\right)\frac{t}{257,14 + t}\right]
```

変更された反応(kmのh、またはメートルのzが付いている0.157 · z)および管のcriterion:

```math
M = N + 157\,h, \qquad \frac{dM}{dh} < 0 \iff \frac{dN}{dh} < -157\ \mathrm{N/km}
```

| dN/dh (N/km) | コンプライアンス | 144のMHzの効果 |
| 0 の 0 | サブリフラクション | 流量を削減 |
| 0から-79まで | ノーマル (標準 約 −40) | 同じ半径 4/3 のラジオ horizon |
| から −79 へ −157 | スーパーリフラクション | 細長い流れ、「良いtoo」 |
| 以下 −15 | conduit (トラップ) | 信号を台無しにして下さい、1000のkm上のDX |

圧力レベルでモデルからNを抽出する方法:T、相対湿度および地質的な高さを取る各レベルのために、NとMを計算し、隣接レベル間の勾配。 地面の下のレベルは捨てられるべきです(アルプスの1000 hPaは地下にあります)。

最小トラップ周波数: 導管は、その厚さと比較してかなり短い波だけを導きます。 Hepburn はテーブルの厚さ → 最小の便利な周波数 ([DX 情報センター](https://www.dxinfocentre.com/propagation/luf.htm)); それは、信号が次第に低下する軟限度です。

| 導かれた厚さ | 最低の支払可能な頻度 |
|  61 m  | 962のMHz |
|  91 m  | 464のMHz |
|  122 m  | 276のMHz |
|  152 m  | 185のMHz |
|  183 m  | 133のMHz |
|  213 m  | 101のMHz |
|  305 m  | 53のMHz |

VHF範囲(多くの場合、120〜300 m)では、テーブル値は定数に関する非常によく法律に従う。 100 m未満の式は30〜40%までの周波数を過小評価する。 自分自身を適応させる(Hepburnによって公開された式ではありません)、メートル内のfとdで:

```math
f_{min} \approx \frac{3,3\times10^{5}}{d^{3/2}} \ \mathrm{MHz} \quad\Rightarrow\quad d_{144} \approx 175\ \mathrm{m}, \quad d_{432} \approx 85\ \mathrm{m}
```

練習中:2mは、少なくとも170〜180mの水路を取るため、70cmは半分ほど十分です。 ネット上で循環する式, λmax = 0.014 · d^1.5, ケラーから来ます (1951, 章 1, eq. 18) そして、 λ センチメートルと立って, M が線形に落ちる水路のために: これらの単位は約 2 m 180 m と約 70 cm 89 m の, それはそれから来るヘップバーンテーブルの同じ値です. ケラーはネットカットではないことを警告します。数回も波が絡み、少し「損失」する方法は、小路の駅でもレセプションを向上させることができます。 2019年IEEEアクセス研究では、古典的なメソッド(Kerr、Kukushkin)が実際のカット([Shi et al. 2019](https://doaj.org/article/d431fc16b2104524860927ac92dc1c53))を記述しないことを確認します。閾値は、壁ではなく、表示として使用されるべきです。

ノート: [DJ5AR, カテゴリ](https://dj5ar.de/?cat=174)(Magonza, 21 記事 2017–2023, 2 m–13 cm). 事例紹介:アイルランド(23年5月～2月20日)、 FT8 からベラルーシ(2020年9月)、アルプスとアドリアティック(8月2017年)のイタリア・ドイツに数週間実施。 あなたが地面から使用できない「too High」ダクト(逆1000m)のケースを認識する:駅のそれと水路の共有を比較する必要がある別の確認。 パリ、ボルドー、DWDの縦型プロファイル(最大1028km)と絞り測定として放射状物質を使用しています。

概要では、一般的なレシピ: 垂直プロファイル → N と M レベル → dM/dh ネガティブ → ベース、トップ、厚さ、ダクト → インデックスの力を持つ層。 Hepburn の "secret" 部分は、スポットでリメイクできる、実際のイベントの定期的な校正です。

## 6. プログラムに便利な式

NとM(基本物理セクション)に加えて、これらは垂直からポイント番号に移動し、パスに使用されます。 ITU式は、部分的にPDF読み取りによって再構築されました。 22 11月には、公式のテキスト([ITU-R P.452-18](https://www.itu.int/dms_pubrec/itu-r/rec/p/R-REC-P.452-18-202310-I!!PDF-E.pdf)、P.453-14、P.526-16、P.372-18)でレビューされ、コードで修正されました。 troposcatter 190の定数(190,1)とガスの吸収= 3 g/m3; α未満 - 3,4e qe qe と qetraposcatter 190の割合は、254e qe と5e qe qe は、 qe または q は、 qe に制限されます。 Rumore P.372-18:テーブル1および銀河対応;人工的な騒音のカーブは250のMHzまでであり、プログラムは同じ法を拡張するおよそ100のMHzまで銀河は、です。

1。 モデルの2つのレベル(hのkm、単位Mの)間の勾配:

```math
\frac{dM}{dh}\Big|_{i} = \frac{M_{i+1} - M_{i}}{h_{i+1} - h_{i}}, \qquad \text{condotto se } \frac{dM}{dh} < 0
```

2。 導管強度と厚さ:厚さd =トップ-ベース(土壌ダクト、ベース=土壌)、ベースとトップの間のM欠乏としての強さ。

```math
d = h_{cima} - h_{base}, \qquad \Delta M = M_{base} - M_{min}
```

3。 地球の半径の同等の要因(P.452-18、eq. 5および6a)、ΔN = N/kmの最初のkm、肯定的なNの低下の平均Nの:

```math
k_{50} = \frac{157}{157 - \Delta N}, \qquad a_e = k_{50}\cdot 6371\ \mathrm{km}
```

ΔN = 40 では、約 4/3 k (標準大気); 157 k に近づくΔN は無限に傾向があり、つまり、地球のラジオは平らになります: それはダクトの始まりです。

4。 高いアンテナ h メートルのラジオ horizon、km の radius の同等の to\_e を使って:

```math
d_{oriz} \approx \sqrt{2\,a_e\,h/1000}\ \ \mathrm{km}\quad(\text{con } k = 4/3:\ d \approx 4,12\sqrt{h})
```

5。 緯度(P.452-18、eq.2)のダクトの確率、時間の割合;φ = 経路の中心の緯度、μ1およびμ4は海がどれだけ遠くにあるかを考慮に入れます:

```math
\beta_0 = 10^{\,-0,015|\varphi| + 1,67}\ \mu_1\,\mu_4\ \%\qquad (|\varphi| \le 70^\circ)
```

## 14. LIVETROPOVHFインデックス仮説

提案を開始するには、ヘップバーンと同じ規模のインデックス0～10で、グリッドの各点と、GFS(ECMWFと比較のためのICON)から3時間ごとに計算され、ルートのどの部分が選択したバンドに有用なダクトに渡されるかを言う2番目の数値を議論する。 下の体重は私の仮定です。

BeanとDuttonとKerrの後にレビュー:プロファイルのしきい値は、そのテーブル6.5から来ており、その測定値からスケールを拡大するので、屈折層は通常のプロファイルよりも10〜25dB価値があります。 インデックスはdBで最初に計算され、0～10で計算されます。そのスシザーの値はスポットに較正されるままです。

1. T の排出、相対湿度、1000、975、950、925、900、850、800、700、600 および 500 hPa、および T および 2 つの m の湿気、地上圧力、層の高さおよび風 10 m の。

ルートによる計算(2つのロケータ間で): 既にパス上のインデックスのプログラムを行い、有用なダクトとベースの平均的なシェアでポイントの割合を計算するので、10キロごとに最大円をサンプリングします。 CSIROの研究では、パイプラインの経路の有用な部分(AISのルートで162MHzは制御ケースよりも67%高い)を発見しました。

ルートごとの計算を追加する( LA0BY と W3SZ から):(1)の海局は、コンジットのベースとトップと比較して、高いコンジットは、入る人々だけに役立つので、;(2)イエの方法でトロポスキャッター「床」を、地面のプロファイルから取られた開始コーナーで; dBのトロープゲインは、その損失から削除され、その結果はステーションが( KK6MC テーブル)を克服するために管理する損失と比較されます。 そのため、指数も到達可能な距離の推定値になります。

一度に試すための修正(BeanとDuttonと LA0BY 、 IK3XTV 、既にマニュアルで G4MCU から)、スポットとの比較を向上させる場合にのみ保存されます。

- 混合(毎日観察することによって、作者によると重要な):地球上の日、午前中と午後の澄んだ空の間、またはいくつかのm /秒の上に地面に風が吹いて、地面にダクトが消えます。彼らの貢献は減少しなければなりません。 海ではございません。
- 日の時刻(毎日観察することによって、作者によると重要な):灌漑ダクトは日の出の後に日没と秋に生まれます。それは3時間の予報制御です。
- 縦の動き:850–700に上がる空気 hPa はレイヤー(負補正)をリミックスし、抗サイクロンの下にある空気がそれらを強化します(陽性)。
- 圧力の傾向: 最後の時間、より高いおよび安定した信号のパスの上り坂圧力; 減少では、信号(bastano 2 hPa)を下げて下さい。
- 同義語: 1025 hPa の上の高圧、地面のそれの上の 850 hPa の温度、より冷たい海、海による道で流れる熱く、乾燥した空気。
- マウンテンパス:2番目の "convective"インデックス(セクション IK3XTV)、午後の制限層は、パスと高圧に沿ってリッジよりも高い。

VHF/UHF DXから ブック、他の修正を試してみる:ポイント(より多くの日、より多くのポイント)上の高圧の連続日、抗サイクロン(エッジのbonus)の中心と比較して位置、風の測定として地面に圧力勾配、前の24時間(罰)の強い雨、層の端で低い雲(ハイバンドのみの罰)。 経路の方向へ:イソバレのルートのアジマスを比較します。
