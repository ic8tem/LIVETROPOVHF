# 144MHz以上のトロープを形成する方法

> イタリア語からの機械翻訳です。疑問がある場合はイタリア語版のガイドが優先します。

144、432、マイクロ波が地平を超えて行くとき、空気の中で何が起こるか:反応、反転、ダクト、スキャッター、およびプログラムマップでそれらを読み込む方法。 2026年11月9日 バージョン

## まとめ

- VHF波は、大気(大気)の最初のキロで旅行し、 [3] [7] [11] で屈折率が変化する曲がる。
- 指数は、圧力、温度、およびすべての [11] の湿気の上の依存する屈折性Nと測定されます。
- 通常の雰囲気では、約40キロ単位です。 1キロあたり157ユニット以上を落とすと、 [7] [11] コンジットに閉じ込められています。
- 導管は、上の乾燥空気と下で湿った熱間反転から来ています。 抗サイクロン、海、穏やかな夜、 [3] [4] [5] [13] フロント。
- 頻度が高い、より薄いダクトは十分です:マイクロウェーブは144 [3] [7] より頻繁に開きます。
- conduitなしではtropospherの散布剤を残します: 常に存在する、弱い、それは距離 [6] と落ちます。
- プログラムで: 高圧 + 逆 + ヘップバーン/ F5LEN 高 = 確率的な条件; スポットは [1] [2] [13] [14] を確認します。

## 1. 起こる場所: troposphere

大気の最も低い層で、約10〜12kmです。 主に最初の3キロのトロープカウントのために:水蒸気と反転があり、地上 [4] のステーション間の無線ルートを渡します。 正常な状態の下のメートル [3] ごとの約6.5 °Cの高度との温度の低下。 一方、レイヤーでは、温度が高度に上昇し、ほとんどすべての強いトロポの開口部の開始点です。

VHF は、他の時間と他の距離 [5] を持つ HF (サルブとスプラディック) の ionosphere によって反映されません。: 地にそれらを曲げたり、それらを広めたりした場合だけ、地平線を超えて。

## 2. 屈折と屈折 N

別の空気の屈折率が付いている空気によって曲げられる電波。 インデックス n は 1 に非常に近いので、リアクティブ N が使われます。 n − 1 は 100 万 x0Q のマルチプライドです。 [11]

```math
N = (n - 1) \cdot 10^{6} = \frac{77,6}{T} \left( P + 4810 \, \frac{e}{T} \right)
```

ケビンの温度と hPa の水蒸気の圧力を hPa で、T で圧力。 N土壌は通常300〜400です。 2 番目の用語, 蒸気の, 多くの重量を量ります: このため、湿度は、 [3] [11] 温度として多くカウントします。.

波が N の値ではなく、クォータ、勾配 dN/dh とどのように変更されるのかは、何です。

| dN/dh (N/km) | コンテンツ | 波の影響 |
| 0 の 0 | サブレフラクション | 波は地面から離れ、より短い地平線 |
| 0から-79まで | ノーマル (標準 -39) | 地面に曲がるライト:光学1の4/3についての無線horizon |
| から −79 へ −157 | スーパーリフラクション | 波はより多くの曲げます、高められた流動度 |
| −157未満 | コンテンツ | 地球以上の波が曲げ、閉じ込められたまま |

−157 N/kmのしきい値は、地球 [7] [11] の半径の湾曲が等しい点です。 したがって、 [6] スキャッターの計算で使用される8497 km (4/3 の実質の半径)の「同等の地上梁」。

## 3. 反転: トロポ モーター

高度のメートル数メートルでNを崩壊させる必要がある-157 N/kmの下の勾配。 新鮮な湿気の多い空気の層の上に暖かさと乾燥が見つかったとき、それは起こります:温度上昇と蒸気が一緒に落ち、両方のN [3] [5] を降ります。 LA0BY は 6.5 °C [3] の正常な減少に対する km ごとの 10–15 °C までのバージョンを示します。

Inversionsは異なる方法で発生する:

- 反シクロネのSubsidence。 高圧では、高度の空気がゆっくりと落ち、地面に新鮮で湿気の多い空気が残っている間、それは圧縮し、暖まります。 [3] [4] [13] のの最後の日は長く、より長い開始の原因です。
- ノクタール放射線。 穏やかな空と弱い風で土は夜に冷やし、接触空気を冷却します。 朝の太陽で休憩する低逆。 夏と秋の代表的な夕方と朝の開口部。
- 海の警告。 寒い海の上に地面から来る熱く乾燥した空気:海層は湿ったまま、冷やします。 ここから素晴らしい海航路(Atlantic、地中海、北海) [4] [13] 。
- フロント 暖かい前部の前部では、熱気は風邪の上に流れます; 開口部は短く、額に続く。
- 蒸発。 海の上には、最初のメートルで、湿度はすぐに高度で低下します。非常に薄いダクト、電子レンジにのみ便利です。

逆が縦のプロファイル(radiosondaggi):温度上昇と露点が同じセクション [5] で下がっていることを示す。 このプログラムは、熱間反転層(地面よりも925hPaの暖かさで)と850hPaの隔壁でこれの手掛かりを示しています。

## 4. 表面および高いダクト

conduit は、上端(inversion)と下端( [7])との間の境界で波が移動するレイヤーです。

- 表面のパイプライン: 地面か海。 特に海岸の低高度の場所は、直接入ります。
- 高度のパイプライン:500と2000 mの間で、例えば高度に、あります。 平野の駅は、丘や山の中にある人が水路に入ると感じられないかもしれません。 アルプスまたは他の [3] 救済 [4] を交差するリンクを説明します。

導管に入るためには、波はほぼ水平に始まります:地平線の低いアンテナおよび隣接する障害物無し。 路上では、自由空間よりもはるかに低く、距離は1000〜2000キロ以上(例えば、イベリア半島、カナリア諸島、イングランド、またはスカンジナビアと南ロシア間の接続) [3] に達する。

## 5. 周波数: マイクロ波がより頻繁に開く理由

厚みに比べ、非常に短い波だけを閉じ込めます。 細いダクトからの長い波「出ます」。短いものはありません。 それから [3] [7]:

| バンド | 波長(mm) | 必要なもの |
| 144のMHz |  2 m  | 厚いパイプライン(メートルの摂氏)、広く、よくマークされたバージョン:より少ない頻繁しかし非常に広範な開口部 |
| 432のMHz | 70センチメートル | 薄いエッジ: しばしば 144 が「商品」のみであるときに開きます |
| 1296のMHz | 23センチメートル | 弱い反転を縫います。夏に頻繁に海に長いルート |
| 10 GHzの | 3センチメートル | 海に蒸発ダクトするだけで、雨の吸収もカウント |

そのため、モデスト・トロポ・インデックスは既にUHFとマイクロ波で開くことを意味し、144は高い値を求めています。 一方、同じ水路では、144は水路の外に損失が少なく、境界領域を覆います。

## 6. Troposferスキャッター

逆転せずにも、トロポスフィアは均一ではありません。 気温と湿度の不規則性は、地平線を超えてエネルギーの小さな部分を広げます。 これは、優れた [6] ステーションで300〜800キロの接続を可能にする、常に存在する、トラポスフェリック散布器です。 信号は弱く変動します;損失は拡散の角度と成長します、それは距離と地平線上の障害物とあります:

```math
L_{s} = 21 + 10\, \theta_{s} + 10 \log f
```

θs と MHz の ° および f の拡散の角度 [6]. プログラムは、各スポットのタブでこの式を使用して、リンクがスキャッターで説明できるか、コンジットを必要とするかを伝えます(ドキュメント1)。 地面に高いN値が [6] スキャッターを改善します。

エアスキャッター(飛行機の反射:数秒の信号、ドップラー)とスキャッターのメテラー(メテラーの反射)と混同するべきではありません。

## 7. 天気画像:マップでそれを読み込む方法

トロポの開口部は気象に従います。 典型的な状態 [3] [4] [13]:

- 安定した抗サイクロン、高圧(1020〜1025 hPa以上)、広い分離、小さな風:逆転。 最高の開口部は、特に海の上、抗サイクロンのエッジに従ってください。
- Calo dellaのpressione:反転が壊れます。 G4MCU は1012 hPa [13] への圧力低下まで SK6VHF のビーコンに続きます。
- 地上の新鮮な空気の上に高度(上昇850 hPaの他の)の熱風:逆。
- 導電性細胞および重力波(例えばアルプスの下風)はローカルおよび短い開始 [4] を作成できます。
- 日の時刻: 照射からの反転は、夕方と早朝に強くなります。 副産物も一日中残ります。

Hepburn [1] と F5LEN [2] インデックスは、天候モデルからすべてこれをまとめて配置します。 様々なクォータでNを計算し、グラデーションを数値やクラスに変換します。 私は保証ではありません: LA0BY は、高温で表示され、Hepburn [3] では見えないLA- UA6 イベントを示しています。 このプログラムでは、インデックス、アイボレー、温度、および実際のスポットを一緒に表示します。スポットがアンチサイクロンの下に高いインデックス領域に整列する場合、開口部が進行しています。 KP4MD は、WSPR レポートの SNR を Hepburn [14] が提供するウィンドウで 144 MHz の成長権利に見つけました。

## 8. 実用的なリスト

1. エリアのtropoインデックスと、関心のある方向に沿って、次の数時間を探します。
2. isobare: 高圧および広い点は、パスの横または横にあります。
3. サーマルインバージョンとT 850 hPaをオンにします。パス上の高度で熱風。
4. 海と夕方、朝の時間帯に好むルート。
5. 丘の上にいると、高いダクトを考える。 海岸にいたら、表面に。
6. 最高のバンド(432, 1296)を最初にお試しください:最初に開きます。
7. スポットとPSKReporterで確認:同じ方向の長い行は、ダクトを確認します。
