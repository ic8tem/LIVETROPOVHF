## 0

Publik FM-DX Webserver (server.fmdx.org, projek sumber terbuka oleh M. Farkaš): 60 terdekat dalam 1500 km, setiap tiga menit, pada API publik mereka. Jika sebuah server web menerima sebuah stasiun FM lebih dari 150 km dengan sinyal paling tidak 10 dBf (pemancar dikenali oleh PI RDS), penerimaan muncul pada peta sebagai baris ungu; mereka lebih dari 300 km masuk koridor dari 144 band, karena tropo dalam FM (888-108 MHz) berjalan bergandengan tangan dengan 2 m.
